# Vibe Player — CodeAlpha Task 4

A responsive music player built with HTML, CSS and vanilla JavaScript.

## Features
- Play, pause, next and previous controls
- Song title and duration display
- Seekable progress bar and volume control
- Upload multiple audio files from your device
- Playlist with remove-track option
- Shuffle and repeat controls
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Click **Add music** and select audio files stored on your device.

Audio files are selected locally in the browser. They are not uploaded to a server.

## GitHub Pages
In your repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save. Wait for the published URL to appear.
